# 💎 Evol Jewels AI Kiosk

An AI-powered jewelry recommendation system that transforms your Excel database into an intelligent, interactive kiosk experience with direct e-commerce integration.

## 🎯 What This Does

**Transforms your static Excel file into:**
- 🤖 AI-powered semantic search
- 🛍️ Direct links to Evol Jewels website
- 🎨 Beautiful kiosk interface
- 💡 Personalized recommendations
- ⚡ Lightning-fast search (sub-100ms)

## 🚀 Quick Start (3 Simple Steps)

### 1. Install Dependencies
```bash
uv sync
```

### 2. Add Your Dataset
Place your Excel file in the `data/` folder and name it `Evol Jewels Hackathon Database .xlsx`

**Required columns:** Product Name, Category, Price, Collection Name, Images

### 3. Run Preprocessing (One-time setup)
```bash
uv run python src/preprocess.py
```
**This will:**
- Load your Excel data (60+ products)
- Generate AI embeddings for semantic search
- Create direct links to Evol Jewels website
- Build lightning-fast search index
- Save everything to `indexed_data/` folder

### 4. Launch the App
```bash
uv run streamlit run src/app.py
```
Open your browser at `http://localhost:8501`

## 🎯 Features

- **🤖 AI-Powered Search**: Natural language queries with semantic understanding
- **🛍️ Direct E-commerce Links**: Click to view products on Evol Jewels website
- **🎨 Guided Experience**: Step-by-step personalization flow
- **💰 Smart Filtering**: Price range, category, and style filters
- **⚡ Real-time Results**: Instant recommendations with similarity scores
- **💎 Beautiful UI**: Kiosk-optimized interface with gold theme

## 🔧 Technical Stack

- **Streamlit**: Web interface
- **Sentence Transformers**: Text embeddings
- **FAISS**: Vector similarity search
- **Pandas**: Data processing
- **OpenPyXL**: Excel file handling

## 📊 Database Transformation

**What happens to your Excel file:**

| **Original Excel** | **Enhanced Database** |
|-------------------|----------------------|
| 5 basic columns | 7 enhanced columns |
| Static product data | AI-searchable with embeddings |
| No search capability | Semantic search with natural language |
| No external links | Direct Evol Jewels website links |
| Manual browsing | Intelligent recommendations |

**New columns added:**
- `description`: AI-optimized searchable text
- `product_url`: Direct link to Evol Jewels product page

## 📝 Dataset Requirements

Your Excel file should contain columns:
- `Product Name` (required)
- `Collection Name`
- `Category`
- `Price`
- `Images` (optional, file paths)
