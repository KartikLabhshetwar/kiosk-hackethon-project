# 💎 Evol Jewels AI Kiosk V2

An advanced AI-powered jewelry recommendation system featuring celebrity inspiration, vibe classification, and intelligent search that transforms your Excel database into a comprehensive kiosk experience.

## 🎯 What This Does

**Transforms your static Excel file into:**
- 🤖 AI-powered semantic search with vector embeddings
- 🌟 Celebrity Inspiration Engine (8+ Bollywood celebrities)
- 🎨 Vibe Classification System (15+ style categories)
- 🛍️ Smart product integration with Evol Jewels
- 💡 Multi-modal personalized recommendations
- ⚡ Lightning-fast search (sub-100ms)
- 🖥️ Kiosk-optimized interface for 55-inch displays

## 🚀 Quick Start (3 Simple Steps)

### 1. Install Dependencies
```bash
uv sync
```

### 2. Add Your Dataset
Place your Excel file in the `data/` folder and name it `Evol Jewels Hackathon Database .xlsx`

**Required columns:** Product Name, Category, Price, Collection Name, Images

### 3. Run Preprocessing (One-time setup)
```bash
uv run python src/preprocess.py
```
**This will:**
- Load your Excel data (60+ products)
- Generate AI embeddings for semantic search
- Auto-classify products by vibe (royal, elegant, modern, etc.)
- Create smart product URLs (only for products with actual links)
- Build lightning-fast FAISS search index
- Save everything to `indexed_data/` folder

### 4. Launch the App
```bash
uv run streamlit run src/app.py
```
Open your browser at `http://localhost:8501`

## 📊 Database Transformation

**What happens to your Excel file:**

| **Original Excel** | **Enhanced Database** |
|-------------------|----------------------|
| 5 basic columns | 12+ enhanced columns |
| Static product data | AI-searchable with embeddings |
| No search capability | Semantic search with natural language |
| No style classification | Auto-classified by 15+ vibes |
| No celebrity mapping | Celebrity inspiration integration |
| No external links | Smart Evol Jewels website links |
| Manual browsing | Multi-modal intelligent recommendations |

**New columns added:**
- `description`: AI-optimized searchable text
- `product_url`: Smart links (only for products with actual URLs)
- `vibes`: Auto-classified style categories
- `primary_vibe`: Main style classification
- `vibe_scores`: Confidence scores for each vibe
- `celebrity_inspiration`: Celebrity style mapping
