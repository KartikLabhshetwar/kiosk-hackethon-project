# Evol Jewels AI Kiosk

An AI-powered jewelry recommendation system that transforms your Excel database into an interactive kiosk experience with celebrity inspiration and intelligent search.

## Quick Start

### 1. Install Dependencies
```bash
uv sync
```

### 2. Add Your Dataset
Place your Excel file in the `data/` folder as `Evol Jewels Hackathon Database .xlsx`

**Required columns:** Product Name, Category, Price, Collection Name, Images

### 3. Run Preprocessing
```bash
uv run python src/preprocess.py
```

### 4. Launch the App
```bash
uv run streamlit run src/app.py
```

## Features

### AI-Powered Search
- Natural language queries with semantic understanding
- Vector similarity search using FAISS
- Sub-100ms search performance

### Celebrity Inspiration
- 8+ Bollywood celebrities with style profiles
- Celebrity-specific recommendations
- Style-based filtering

### Vibe Classification
- 15+ automatic style categories (royal, elegant, modern, etc.)
- AI-powered vibe detection
- Multi-modal recommendations

### 55-Inch Kiosk Interface
- Touch-friendly large buttons (80px+ height)
- Optimized typography for large displays
- Full-screen responsive design
- Professional gold theme

## Technical Stack

- **Frontend**: Streamlit with 55-inch kiosk CSS
- **AI**: Sentence Transformers + FAISS
- **Backend**: FastAPI with Pydantic
- **Data**: Pandas + OpenPyXL

## Database Transformation

| Original Excel | Enhanced Database |
|----------------|-------------------|
| 5 basic columns | 12+ enhanced columns |
| Static data | AI-searchable with embeddings |
| No search | Semantic search with natural language |
| No classification | Auto-classified by 15+ vibes |
| No celebrity mapping | Celebrity inspiration integration |

## Performance

- **Model Download**: ~90MB (first run)
- **Preprocessing**: 1-2 minutes for 1000 products
- **Search Speed**: <100ms
- **Memory Usage**: ~200MB for 1000 products
- **Scalability**: Up to 10,000+ products

## Deployment

### Streamlit Cloud
1. Push to GitHub
2. Connect at [share.streamlit.io](https://share.streamlit.io)
3. Set main file: `src/app.py`
4. Set requirements: `requirements-streamlit.txt`

### Local Kiosk
```bash
# Full-screen mode for physical kiosks
streamlit run src/app.py --server.headless true
```

### FastAPI Backend
```bash
uv run uvicorn src.api:app --reload
```
